# 分析资料与解释边界

## 读数与资源
每条 readings 有 specimen、operator、instrument、replicate、value 和 unit；study_design 声明哪些因子随机抽取、哪些固定，以及设计是交叉还是嵌套。样品真实差异属于研究对象变异，不是重复读数误差。costs 包含人员启用工时、每次测量工时和破坏性样品消耗。
## 分析与规划的边界
新工具需要展示来源分解、可分离程度、模型诊断和不确定性。规划中的对象为 study_design 中的目标总体，输出需要区别绝对一致性和相对排序的精度含义。算法、边界估计与不确定性方法由实现者决定，不强制特定方差分量估计程序。未观测到的交互不可以默认已证实为零。
## 检查材料
analysis_cases 提供完整交叉设计、仪器与人员完全绑定、缺少重复和常数读数。可用简单加性构造核对来源，单独检查负的矩估计或边界拟合如何被解释；比较方案时不能悄悄改变对象总体。改变工时预算只影响候选可行性，不改变原始数据拟合。
